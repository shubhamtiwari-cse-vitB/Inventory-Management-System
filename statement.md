# Project Statement

## 1. Problem Statement

Managing product information, purchases, and invoice records manually can make inventory-related operations difficult to organize and maintain.

The Inventory Management System provides a simple computer-based solution for managing product details, recording purchases, and maintaining invoice information using Python and MySQL.

---

## 2. Project Scope

The project focuses on basic inventory management operations.

The system allows users to:

- Add product information
- Display product information
- Search for products
- Delete products
- Update product details
- Sort products
- Record purchases
- Maintain purchase history
- Manage invoice records

The system stores the information in a MySQL database.

---

## 3. Target Users

The system is intended for users who need to manage basic inventory and product records, such as:

- Small businesses
- Shop or store operators
- Inventory managers
- Students learning database-based applications

---

## 4. High-Level Features

### Product Management
- Add new products
- Display product details
- Search products
- Delete products
- Update product information
- Sort products

### Purchase Management
- Record product purchases
- Store customer details
- Store quantity and pricing information
- Maintain purchase records

### Invoice Management
- Generate and store invoice information
- Display invoice records
- Manage invoice records

### Database Management
- Store product information in MySQL
- Store purchase information in MySQL
- Store invoice information in MySQL

---

## 5. Technologies Used

- Python
- MySQL
- MySQL Connector/Python

---

## 6. Project Objective

The main objective of this project is to develop a simple inventory management application that demonstrates the use of Python programming and MySQL database connectivity for performing practical inventory-related operations.
